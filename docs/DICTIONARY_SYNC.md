# 个人词典的语音录入与同步

## 语音录入

词典的“读音”实际是 ASR 输出中需要匹配的原文，不是拼音。录入时使用现有单一 ASR 入口的
`faithful` 模式，关闭热词、个人词典替换和 AI 整理；用户点录音、说出词、再点结束，最终
转写仅填当前词条的读音，写法仍手工填写。原始音频只在内存和办公室 ASR 链路中流转；
录音未完成、结果为空或词条已删除时不覆盖已有内容。词典录音与普通快捷键输入互斥。

## 私网同步

Mac mini 标准 v1 适配服务是这一位用户的唯一同步源，不修改办公室 ASR。`GET
/v1/dictionary` 返回修订号和 `读音 → 写法` 映射；`PUT /v1/dictionary` 使用 `If-Match`
修订号原子更新整份映射，冲突返回 409，客户端重新拉取并按词条合并后重试。两种请求
都必须提供现有项目 Bearer Token，遵守当前 Tailnet 设备准入；不开放公网或跨项目复用。

同步前客户端保留上一份成功同步的基线（与当前词典一起加密保存在本机）。三方合并比较
基线、本机、服务器的每个读音：只有一端变化时保留该变化，两端改变不同读音时并存；
同一读音同时发生冲突时保留本机修改并提示。删除也作为相对基线的变化处理，离线期间
的修改和删除可在重新联网后同步，不得用旧整表覆盖另一端新增词条。首次接入时本地
既有词条与服务器词条合并，不清空任一端。仅同步非空、符合协议上限的词条。

mini 将词典用 AES-256-GCM 加密落盘，密钥单独保存在 owner-only 文件中且不进入发布
目录、Git、日志或客户端。服务端只短暂解密于内存，不记录词典正文、音频或请求体。
客户端从已验证的标准 v1 WebSocket 地址派生同主机 HTTP(S) 地址；非标准入口不猜测
或自动回退。同步失败不阻断本地词典使用，界面显示状态并待下一次联网重试。

iOS 主应用负责同步和录音，键盘扩展只消费共享的结果；真机安装仍受 Apple 签名限制。
